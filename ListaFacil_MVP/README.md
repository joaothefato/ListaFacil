# ListaFácil — MVP

## 1. Visão geral
O **ListaFácil** é uma aplicação web responsiva para organização de tarefas pessoais, acadêmicas e profissionais. O objetivo é permitir que qualquer pessoa registre atividades, defina prazos e acompanhe o que já foi concluído em uma interface simples.

## 2. Problema
Muitas pessoas anotam compromissos em diferentes lugares ou dependem da memória para lembrar de atividades. Isso pode causar esquecimentos, atrasos e dificuldade para priorizar tarefas.

## 3. Público-alvo
- Estudantes que precisam organizar trabalhos, provas e atividades;
- Pessoas que desejam controlar tarefas pessoais;
- Profissionais que precisam acompanhar pequenas atividades do dia a dia.

## 4. Proposta de valor
Reunir tarefas em um só lugar, com cadastro rápido, prazo, categoria e acompanhamento visual de conclusão. A aplicação funciona diretamente no navegador e não exige criação de conta no MVP.

## 5. Funcionalidades do MVP
1. Cadastrar uma tarefa com nome, data e categoria;
2. Visualizar todas as tarefas;
3. Marcar tarefas como concluídas ou pendentes;
4. Excluir tarefas;
5. Pesquisar tarefas pelo nome ou categoria;
6. Filtrar por todas, pendentes, concluídas e tarefas de hoje;
7. Visualizar indicadores de total, concluídas e pendentes;
8. Salvar os dados localmente no navegador usando `localStorage`.

## 6. Tecnologias
- HTML5 para estrutura;
- CSS3 para identidade visual e responsividade;
- JavaScript para interação;
- LocalStorage para persistência local;
- GitHub Pages para hospedagem gratuita.

## 7. Como executar
Abra o arquivo `index.html` em um navegador. Para publicar, envie os arquivos do projeto para um repositório GitHub e ative o GitHub Pages nas configurações, selecionando a branch `main` e a pasta `/root`.

## 8. Limitações conhecidas
- Os dados ficam armazenados apenas no navegador e dispositivo utilizados;
- Não há login, sincronização entre usuários ou banco de dados em nuvem;
- O MVP não envia notificações automáticas.

## 9. Melhorias futuras
- Cadastro e login de usuários;
- Sincronização em nuvem;
- Notificações de prazo;
- Compartilhamento de listas;
- Calendário mensal e relatórios de produtividade.

## 10. Modelo de negócio
A versão básica pode ser gratuita. Futuramente, a receita poderá vir de um plano Premium com sincronização, listas compartilhadas, relatórios e personalização, além de parcerias institucionais com escolas e cursos.
